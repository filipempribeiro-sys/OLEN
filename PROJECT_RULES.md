# PROJECT_RULES

1. A ALPHA (`outdoor-alpha-1`) não é alterada durante o desenvolvimento da OLEN.
2. Não criar workflows automáticos de GitHub Actions para builds, releases ou wakes.
3. Não acordar/testar Render/backend sem autorização explícita.
4. GitHub Pages pode publicar automaticamente como exceção de baixo custo.
5. Manter internals proprietários do Reality Engine fora deste repositório público.
6. Preferir testes locais/determinísticos e alterações reversíveis.
