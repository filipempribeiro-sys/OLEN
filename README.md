# OLEN

Repositório independente de desenvolvimento e validação da nova aplicação OLEN.

## Estado
- ALPHA permanece congelada em `outdoor-alpha-1`.
- Este repositório não usa o service worker, patches legacy ou runtime 4.x da ALPHA.
- Sem Render/backend automático e sem GitHub Actions automáticas.
- O frontend experimental parte do UX aprovado e evolui aqui até validação 5/5.

## Estrutura
- `index.html` — UX de teste independente.
- `js/` — módulos OLEN 5 reutilizáveis migrados da ALPHA.
- `assets/` — identidade visual oficial (wordmark, splash background e app icon).

## Regra de integração
Só depois de a OLEN estar visual e funcionalmente validada será preparada uma integração controlada com a ALPHA e os serviços/API existentes.
